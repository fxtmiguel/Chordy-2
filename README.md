1. My project teaches user's how to create chords for the
accordion. The home screen has tabs with different notes 
which represent chords that can be made by combining certain
accordion buttons together. The main purpose of this app is to show
the user how the theory of an accordion works and also test
them on their knowledge after using this app. The progress
feature is great because it allows users to learn at their own
pace and take something away from these lessons by being tested. 
Finally, I believe  using an instrument is a great skill to learn, 
so this app can help beginners focus on the basics.
